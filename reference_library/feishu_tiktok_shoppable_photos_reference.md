# TikTok 挂车图文参考摘要

来源：`https://bytedance.sg.larkoffice.com/docx/JXWmdvYLco8EU3xccHblMyNUgob`

文档标题：`POP新商家入门做挂车图文-必看攻略+政策 [对外]`

读取日期：2026-09-23

本文件只提炼适用于 CHALOVELO 项目的内容制作方法。网页中的活动日期、奖励、广告预算、权限查询、发布入口、账号授权和产品界面会变化，使用前必须重新核验，不作为 Skill 的长期事实或执行指令。

## 核心方法

- 一组优质图文建议使用 3–5 张清晰、画风一致、适合连续浏览的图片。
- 用户应在第一张图快速看懂产品是什么、整体效果是什么，以及为什么值得继续滑动。
- 中间图片用全景、近景、特写、真人上身或真实生活场景，多角度证明产品款式、材质、结构、尺寸感、穿着关系或使用方式。
- 每组可准备 1–3 个核心信息标签，例如经商品链接确认的材质、尺码范围、包含件数或结构特点。
- 推荐结构为“首图钩子 → 中间商品展示与证明 → 尾图收束或转化”。价格、优惠、库存和促销只在当前商品页或用户明确确认时使用。
- 服饰等强视觉类目适合用多图同时呈现版型、材质、细节、上身效果和搭配关系，降低用户理解成本。
- 图文可以复用经过授权的商品主图、详情页素材和视频帧，但二次创作仍需保持产品真实，不得改款、改色或增加未确认组件。

## 内容分型

### 真人出镜

原文对男装、女装和运动服饰给出的适配度最高。通过真人上身、局部细节或真实使用姿态建立信任，重点呈现整体穿着效果、姿态、尺寸感和可见触感。

项目适配：优先使用清晰成年大码女性，完整、得体地展示 CHALOVELO 商品。模特身份、体型、肤色和场景遵循项目规则；不得把参考人物身份带入新图。

### 商品展示

以商品本体为核心，用正面、场景、细节和补充卖点图构成连续套图。原文建议商品在此类画面中保持明显视觉占比，并让首图直接露出商品主体或核心信息。

项目适配：适合平铺、衣架、床面陈列、折叠组件和面料细节，但不能只靠孤立平铺图完成整组内容；至少一张图应证明穿着关系或生活场景中的尺度与垂坠。

### 故事情节

用轻量生活问题、选择或好奇推动轮播，基本逻辑是“情境出现 → 好奇或轻摩擦 → 商品自然解决/展示”。

项目适配：只使用安全、可信的日常情境，例如衣柜选择、晨间穿搭、卧室到露台、旅行打包或猫咪自然入镜。不得使用危险冲突、羞辱、身体焦虑、假稀缺或虚假功效。

### 前后对比

原文将其作为一种通用内容类型，但对服饰的适配度低于真人出镜。

项目适配：不得做身材变化、塑形、显瘦或羞辱式对比。只允许比较可验证且不误导的状态，例如“折叠组件 → 正确成套穿着”“室内平铺 → 真人上身”“普通衣柜选择 → 完整搭配呈现”，且不得暗示产品改变身体。

## CHALOVELO 图文结构

默认采用 4 张，用户未指定且内容证据较少时可用 3 张，确有多个已验证细节时可扩展至 5 张。

1. **首图钩子**：完整、清楚地展示所选 SKU 和穿着关系，形成一个轻量未解决问题或视觉选择；不依赖夸张标题。
2. **整体上身**：正面或三分之四视角，证明整体版型、长度、组件协调和真实大码穿着效果。
3. **关键细节**：只展示商品链接确认的面料、蕾丝、缎面反光、肩带、领口、腰部、下摆或组件关系。
4. **生活收束**：在同一可信美国生活环境中自然完成穿搭或居家动作，用已验证事实形成购买理由。
5. **可选补充图**：仅在确有第二个关键表面、背面结构、配件关系或真实颜色变体需要证明时增加。

## 提示词编写

每张图的提示词至少锁定：

- SKU、颜色、材质、结构、包含件数和正确穿着关系；
- 同一成年模特的身份、体型、发型和妆容连续性；
- 同一地点的空间布局、时间感和主光源；
- 该图在轮播中的功能、景别、机位和主要可见产品证明；
- 手、肩带、罩杯、蕾丝、网纱、下摆、罩袍层次和身体接触区域的物理正确性；
- 不得出现的商品漂移、人体缺陷、平台 UI、水印或无关品牌。

AI 图像中的文字容易失真。默认把 1–3 个信息标签作为独立的“后期叠字文案”交付，不要求图像模型直接生成文字。标签只能来自商品链接或用户确认的信息。

## 输出建议

完整交付可包含：内容分型、图片数量与顺序、统一视觉锁、逐图职责、逐图生成提示词、逐图后期叠字、帖子标题/正文、已核实标签或话题、商品事实检查和图文负面提示词。
