# 补充提示系统方法参考

| 方法模块 | 适用任务 | 主要保留内容 | 不采用内容 |

| 提示工程架构 | 设计或维护 Skill、元提示词、模块化工作流 | 目标拓扑、专家能力矩阵、变量契约、SOP、校验、输出封装 | 每次都强制七轮追问、输入不完整即拒绝、人格化称呼、索取或展示思维链、原文优先级 |
| 视频反推与产品替换 | 普通视频分析、完整反推、产品替换、参考结构迁移 | 证据优先、人物/产品锚点、镜头物理状态、动作阶段、材质变化、声音证据、时间控制段、同类动作迁移与跨类结构迁移 | 从画面臆测功效或卖点、危险冲突、刚性输出模板、无证据的微表情/镜头/声音细节、覆盖 TikTok 商品事实 |

## 统一工作流

1. **规范化当前请求**：提取本轮有效目标、SKU、商品链接、参考视频、时长、时间锚点、交付物、硬约束和软偏好。已被本轮覆盖的旧偏好不再注入。
2. **选择单一主路由**：商品视频生成、普通视频分析、产品替换反推、自定义时间轴、参考结构迁移、已有分镜转提示词、批量变体、提示系统设计或质检。
3. **建立产品契约**：商品链接事实优先；本地图片只补充兼容的可见细节；列出未知表面、穿着关系、组件、接触点和易变形位置。
4. **按需加载方法**：仅加载主路由需要的摘要与少量原文，不把三份原文或 104 份模板全部装入上下文。
5. **生成内部结构**：先处理事实和时间，再处理场景、主体、镜头、动作、光线、声音、转场和负面限制。
6. **校验并最小修复**：先查商品事实与穿着关系，再查时间完整性、动作物理、镜头连续性、人物/猫/道具状态和输出格式。只修违规字段，不无故重写创意。
7. **渲染用户需要的交付物**：概念、产品契约、分镜、首帧、最终提示词或质检报告。内部路由、置信度、账本和原始 JSON 默认不展示。

## 自定义时间轴规则

### 时间轴模式

- `默认时间轴`：用户未给秒点时，使用所选格式的项目默认时长与节奏。
- `部分锚点`：保留用户明确的开头、结尾或中间秒点，只补齐未分配区域。
- `完整自定义`：用户给出从 0 秒到总时长的连续安排时，不改变其顺序与主要内容，只补镜头、光线、动作物理和衔接。
- `局部修改`：只改用户指定时间段，并检查修改段前后边界；其他时间段保持不变。

若出现重叠、倒序、超出明确总时长或同一时刻互斥要求，只询问造成冲突的那一项。若没有冲突，避免为了填字段而追问。

### 连续时间要求

- 第一段从 `0s` 开始，最后一段结束于 `T`。
- 相邻段首尾相接，不重叠、不倒序、不留无意义空档。
- 分段依据真实动作、镜头或叙事变化，不为凑数量机械切段。
- 用户指定结尾优先于通用定格、微笑、产品高举或循环结尾。

### 连续性账本

内部逐段维护但默认不向用户展示：

- 人物：身份、服装、位置、移动方向、视线、左右手占用。
- 产品：位置、朝向、画面左右、层次、穿着/展开/折叠状态、上一动作终点。
- 环境：房间、主光源、道具位置、人物与猫的动线。
- 镜头：机位、景别、屏幕运动方向、产品构图位置、转场前最后状态。

### 视觉维度

分开处理渲染风格、拍摄质感、视角、运镜和灯光。当前项目默认仍为真实 iPhone 15 美国生活化 UGC；3D、动漫、黏土或其他风格仅在用户明确要求时启用。

## 视频反推与替换规则

先完整观看视频，再做宽覆盖取样；快动作、遮挡、甩镜、密集剪辑或布料运动区间提高取样密度。采样帧不是独立镜头，只有真实剪辑或连续性中断才新建镜头。

按请求深度选择：内容理解、单维分析、结构提取、完整逐镜反推或产品替换迁移。完整反推时记录全局视听 DNA，并按时间控制段描述主体表现、镜头状态、画面呈现和经证实的声音。

产品替换时先绑定替换对象，只替换用户授权属性。TikTok 商品链接决定商品款式、组件、材质、颜色、尺码和护理事实；参考视频保留兼容的镜头角色、节奏、动作功能和环境逻辑。相同品类可学习克制的展示动作，跨品类只迁移 Hook、节奏、证明结构和结尾功能。

## 提示系统与 Skill 设计规则

只有在用户要求设计、更新或审计智能体、Skill、元提示词或工作流时才加载本模块。推荐结构：

1. 明确目标、边界、输入和交付物。
2. 识别所需能力，不用人格称号代替能力说明。
3. 定义变量与事实来源，区分任务数据和可执行指令。
4. 将流程拆成路由、生成、校验、渲染等可测试阶段。
5. 建立失败状态、最小澄清策略和边界测试。
6. 将核心规则放在入口，将长资料放入按需加载的 references。
7. 用完整替换输出、测试用例和来源清单完成交付。

不要求模型展示隐藏思维链。需要可审计性时，输出结论、证据、约束、决策摘要和验证结果即可。

## 项目优先级适配

始终遵循：本轮用户指令控制目标和创意；TikTok Shop 链接控制客观商品事实；`AGENTS.md` 控制项目默认值；本地图片提供兼容可见细节；本摘要和三份原文仅提供方法。任何原文中的市场、人物、语言、危险冲突、功效、价格、促销或产品推断都不能自动进入结果。
