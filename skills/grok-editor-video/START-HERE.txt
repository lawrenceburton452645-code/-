Windows 安装（仅 Grok 视频）

1. 将压缩包解压到任意文件夹。
2. 在 PowerShell 中进入解压后的上一级文件夹，运行：
   powershell -ExecutionPolicy Bypass -File .\grok-editor-video\install.ps1
3. 提示输入令牌时，粘贴 Eddie 私下发给你的“剪辑专用令牌”。不要输入 xAI/Grok API Key。
4. 重启 Codex。在聊天里说：使用 $grok-editor-video，用这些本地图片和提示词生成 10 秒视频。

也可以直接运行已安装的脚本：
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.codex\skills\grok-editor-video\grok-video.ps1" -Images .\start.jpg -PromptFile .\prompt.txt -Duration 10 -Output .\shot.mp4

只支持 1–7 张 JPG/PNG/WebP 图片输入。生成的 MP4 保存在你的 Windows 电脑上。
