# Grok｜015、056、001 模特上身合成优化提示词

版本：2026-10-13｜用途：给同事使用的图片换装与错误修复工作包。

**核心做法：一款一组参考、一轮一个目标。先得到衣服结构正确的静态上身图，再做场景变化或图生视频。**

本文结合项目商品库、实见产品图、飞书与即梦方法摘要、Gemini Gem 产品稳定方法、Super Video 分阶段质检方法，以及已有 Grok 001 批次质检记录整理。针对 Grok 图片编辑编写，不把项目的视频中转脚本当作图片换装工具。

这是待实测的优化方案。本次没有提交图片或视频生成，没有同事的原提示词、失败截图和任务日志，因此不能确定他的具体失败原因，也不能承诺降低多少失败率或保证通过审核。

## 1. 同事可以先这样用

1. 只选一个 SKU、一个颜色和一位明确成年大码模特。
2. 把模特底图定义为 A，把本款商品图定义为 B 系列，按第 3 节分配用途。
3. 先完成第 4 节输入检查；参考不足时按说明缩小目标，不补造结构。
4. 使用第 6、7、8 节中对应款号的主提示词，先合成一张正面或轻微三分之四侧身的静态上身图。
5. 按第 10 节核对衣服；只有一两个局部错误时，使用第 9 节中对应的一条修复词。
6. 通过后保存为母图 M。后续修改以 M 为底图，不再让 Grok 从原模特图重新猜一套衣服。

**使用前需要替换提示词中的 `【人物实见描述】`，并确认 A 的姿态、背景和光线与所选提示词相符。**这不是要求把原模特改成示例人物。已有 A 与示例背景不同，就把背景、光线段替换成 A 的实际情况；若要另换场景，单独准备新底图，再换装。

本文主提示词服务于单张合成母图，不是四张带货图套组，也不是视频脚本，因此不加入猫、口播、开头动作、转场、价格或发布文案。

## 2. 先分清“失败”是哪一类

| 现象 | 优先检查 | 处理方式 |
| --- | --- | --- |
| 只回复文字，没有图片 | 当前是否进入图片生成/编辑流程，图片是否实际附上 | 使用当前入口支持的图片编辑功能；不要仅让文本助手分析图片 |
| 明确提示内容审核拒绝 | 请求、输入图片或生成结果是否不被该入口接受 | 记录提示，停止该请求；可改为商品平铺、衣架展示等不同呈现目标，不用暗语或反复重提交绕过限制 |
| 超时、网络错误、限流、服务错误 | 上传状态、账号额度、任务状态、网络、第三方中转错误 | 先查任务是否仍在运行或已经完成，避免重复提交；文字优化不能修复服务故障 |
| 有图，但模特换脸、变瘦 | 人物图和商品图是否混用，多张人物图是否互相冲突 | 指定 A 是唯一人物来源，B 只提供服装；保留 A 的体型和姿态 |
| 有图，但衣服错款或少部件 | 商品关系是否写清，是否把未知面或不同变体混在一起 | 用对应 SKU 的独立产品锁，检查参考缺口 |
| 静态图正确，视频中变形 | 动作、遮挡、转身、镜头是否过复杂 | 先锁母图，再减少动作；这是视频问题，不计入图片换装失败 |

不要把“下载成功”“生成成功”与“商品准确”混为一项。

### 项目里已经有的证据

- 001 的既有 Grok 视频批次记录多次出现：鱼网袜被简化成薄纱袜、擅自加摸衣或拨发动作、转身幅度增加、叠化和裁头。
- `SKU001_visual_20261012/review/QA.md` 记录一个 10 任务的视频批次中有 1 个 `imagine:content-moderated` 拒绝，另外 9 个返回视频。这只是该批次的观察，**不是 001 图片换装的失败概率，更不是三个 SKU 的整体失败率**。
- 当前没有同事的 015、056 图片失败样本。下文对这两款的风险判断来自衣服的结构复杂度与参考图冲突，属于待验证的诊断方向。

## 3. Grok 的参考图绑定方法

### 3.1 区分入口

Grok 图片编辑和多图编辑能够以现有图片为来源；官方多图编辑文档说明可按提交顺序引用输入图片。建议实际提交时使用“第 1 张图是 A、第 2 张图是 B1……”的对应关系，并在当前界面核对附件顺序。[官方多图编辑文档](https://docs.x.ai/developers/model-capabilities/images/multi-image-editing)

这项 API 能力不代表你同事的网页版、App 或第三方入口一定显示相同选项。以下用 A/B 标记表达参考用途，不是 Grok 的专用语法，也不会自动绑定本地路径。

| 路线 | 当前任务怎么用 |
| --- | --- |
| Grok 网页/App 图片编辑 | 实际附上模特与产品图片，明确底图和服装参考；界面能否多图、选中底图或局部编辑，以当前可见功能为准 |
| 官方图片 API | 使用当前官方图片编辑接口；不要把文生图接口当成已经绑定模特图的编辑请求 |
| 第三方图片入口 | 先确认真的接收人物和服装图片，以及底图的选择方式；记录实际返回的模型与错误 |
| 本项目 `grok-video.ps1` | 用于视频生成和下载，不用于静态图片换装。其限制只属于这份视频脚本 |

**文件名、款号和提示词里的路径不能替代图片附件。**“穿上 015”并不会让 Grok 自动读取本项目产品库。

### 3.2 每张图只承担一种主要职责

| 标记 | 用途 | 不得带入的内容 |
| --- | --- | --- |
| A | 唯一模特底图；人物、脸、身体比例、原姿态、构图与场景 | 不把 A 原来穿的衣服保留成新套装的一部分 |
| B1 | 当前 SKU、当前颜色的正面衣服与穿着关系 | 商品图中其他人物的脸、体型、姿态、背景、妆容 |
| B2 | 当前视角确实需要的部件或细节，例如袜纹、短裤 | 不同款号的结构、未确认的同类配件 |
| B3 | 需要时补充已核对的同款背面 | 未确认的背面设计、另一个变体的颜色或附件 |
| M | 已通过衣服验收的上身母图 | 原始商品图的人物身份或错误候选图的结构 |

起步优先使用 A+B1；缺少必要信息再加入 B2。001 往往需要额外袜子细节，056 全套短裤穿法需要真实短裤图。**这是减少参考冲突的工作建议，不是图片数量越少就必然越好的定律。**

选图时优先使用清晰、完整、同颜色、同视角的参考。可以在当前工具允许时裁去商品图中的无关脸部、文字和边框，但保留肩带端点、下摆、袜口及连接位置。裁图不能改款、改透明度或修掉不喜欢的商品细节。

不要一轮同时上传 015、056、001；不要把白色正面、酒红色侧面与黑色背面一起作为同一变体的外观参考。

## 4. 输入底图检查：这里做错，提示词很难补救

- 模特明确成年，建议 25 岁以上；使用可用于本次创作的人物素材。当前项目选角范围为拉丁裔/西语裔、白人/欧洲裔、黑人/非洲裔成年大码女性。已有模特的脸、肤色和体型不因换装而重做。
- 模特原图应覆盖本次要展示的部位。只有头像时，不承诺“保留原体型并精准换装”；选择完整底图。缺失身体若另行生成，必须把它当作新生成部分。
- 优先自然站立、双脚不交叉、双臂放松、手离开领口和下摆。不要同时要求保持复杂原姿态，又要求全新站姿。
- 长发不覆盖关键肩带；手臂和道具不挡住核心商品结构。需要调整遮挡时，先做独立底图准备。
- 001 的构图至少清楚覆盖短裙、袜口和一段鱼网纹；015 要能看到长袍下摆；056 要能分辨两个短裤裤腿。
- 原图的服装若与目标差异很大，采用分步编辑；但不要使用脱衣、中间裸露或增加透视的过渡图。
- 模特底图与产品参考的摄影角度尽量相容。正面平铺图不用于精确推导未知背面。
- 原图背景和光线与本次目标不同：先单独换背景，或沿用实际背景重新写环境段。不要把“保留背景”和“换成卧室”放在同一轮。

### 人物实见描述怎么填

在三款主提示词的 `【人物实见描述】` 位置写一段经过人工核对的选角与外貌，例如：

> 创作设定为 32 岁的白人/欧洲裔成年女性；椭圆脸，下颌略圆，深棕色头发扎低马尾，棕色眼睛，浅肤色有少量雀斑，淡妆，眉毛与左右脸轮廓保留自然不对称。

这里只是填写示例，**不是对未提供的模特图作身份识别**。实际使用时应按自己的成年模特设定和图中可见外貌改写，避免与 A 冲突。身高体重采用下文内部 AI 造型设定；若已有真实数据，用实际数据替换，不把估计值写成测量事实。

## 6. 015 主提示词：先保持三层分离

### 准备

- A：已核对成年模特底图，正面自然站立，手不挡内搭；长袍展示范围完整。
- B1：`015酒红色.png`，用于酒红色正面衣服结构。
- 若用其他颜色，B1 与提示词颜色必须一起替换。
- 此模板不生成未证实的背面，也不把重叠商品名称扩成第五件。

### 主提示词


官方提示词指南区分完整新图与局部编辑：已有主体和布局正确时，先点明要改的细节，再说明保留的场景；把整套新提示词贴进每次小修可能使画面重新布置。本包主模板用于首次完整换装，后续小修使用下面的短指令。[官方图片提示词指南](https://docs.x.ai/developers/model-capabilities/images/prompting-guide)

### 9.1 015｜外袍与内搭粘成一件

```text
修复015外袍门襟与内搭的边界：外袍是独立最外层，两条门襟分别沿身体左右垂下；罩杯和纵向拼接属于里面的蕾丝内搭，不与袍边缝合。按同色B1恢复层间阴影与长袖长下摆，保持原透光密度。保留现有脸、体型、下装、丝袜、手脚、构图、房间和光源，不改其他部位。
```

### 9.2 015｜多出一件、丝袜连到袍边

```text
仅移除相对B1凭空多出的独立衣片，并修复前部吊袜端点，使其连接参考所示内搭/吊袜结构与相应袜口，不连接外袍门襟或下摆。不要为了凑商品名称生成第五件，隐藏后部连接保持未知且不补造。其余已正确的衣服、人物、场景和光线保持原样。
```

### 9.3 056｜把内裤当短裤

使用条件：已经补齐并核对 B2 短裤图。没有 B2，停止全套短裤修复。

```text
仅将外部错误的bikini形下装替换为B2所示真实同款纯黑短裤，恢复两个独立裤腿、真实裤脚、腰口与参考荷叶边，内裤穿在短裤里面而不再重复外露。保留原上衣、人物、体型、姿态、房间、构图和窗光，不将内裤外轮廓拉长冒充短裤。
```

### 9.4 056｜缎面变塑料、变透明

```text
仅修复056缎面的光泽与覆盖：恢复不透明黑色缎面、柔和宽高光与真实折痕，黑色阴影里仍能分辨荷叶边。保持现有正确的杯型、两条细肩带、中央蝴蝶结、上下装边界与短裤结构；不改变人物、背景、光源，不新增蕾丝、网纱或塑料镜面反光。
```

### 9.5 001｜鱼网袜被画成薄纱袜

```text
只编辑001两条袜身，将均匀薄纱外观修复为B2的红色鱼网：清楚的连续网线与规则开孔环绕腿部曲面，孔径、方向与透视按参考，袜口保留原蕾丝带。保留袜长、肤色、腿形、吊袜连接、裙体和荷叶边，不把网纹画到裸露皮肤、裙子或背景。脸、身体、房间、光线与构图保持原样。
```

### 9.6 001｜花瓣荷叶边变流苏、裙体消失

```text
只修复001腰线以下的短褶裥细网纱裙与下摆，按B1恢复连续裙体和一圈密集花瓣状荷叶边；花瓣边来自参考的轻薄叠层，不能变成长条流苏。保留原杯型、胸前装饰带、前中蕾丝、袜口、鱼网袜与吊袜端点，不把裙子改成独立半裙，不改变人物与场景。
```

若裙体已经消失、杯型也变了、袜子也错了，属于大范围错款，不同时拼接三条修复词继续试。回到已核对的底图和参考，检查失败原因。

### 9.7 肩带重复、连接悬空

```text
只修复所标记的肩带与连接端点，使每条带沿本款参考的真实路径接到相应杯边或背片，保留参考实际带数与五金，不把装饰带误删成普通两肩带款。保持原罩杯、衣身、领口、脸、体型、姿态与背景，接触处有轻微阴影，不浮在皮肤上。
```

注意：056通常是两条细肩带；001还有胸前装饰带。不能把“只有两条带”当作通用修复规则。

### 9.8 人物换脸或大幅瘦身

脸与全身体型都明显改变时，优先回到 A 重新做衣服替换，不在错误人物上继续叠修。

仅小范围脸部漂移、商品其余已正确时，可尝试一次：

```text
仅将当前人物漂移的面部恢复为A的同一张脸，保持A的脸型、五官相对位置、原肤色、发际线与自然皮肤纹理，不改变年龄设定。现有已经正确的衣服、身体、发型、姿态、构图、房间和光线保持不动，不带入商品图人物。
```

## 10. 验收与停止规则

按顺序检查，前一项没过就不要继续美化。

| 检查 | 015 | 056 | 001 |
| --- | --- | --- | --- |
| 款式 | 长袍与内搭分离，不变单件短裙 | 吊带与真实短裤分离，不变连体衣 | babydoll连贯上身与短裙，不变文胸加半裙 |
| 材质 | 蕾丝、网纱、原透光密度 | 不透明缎面，光泽有折痕 | 花卉蕾丝、细网纱、鱼网袜分别可读 |
| 件与穿法 | 不按重叠名称扩成五件 | 三件存在关系正确，内裤不强行外露 | 一双袜，内裤不冒充已确认随附件 |
| 关键边界 | 袍袖、袍边、罩杯、内搭下装分界 | 胸下接缝、荷叶下摆、腰口、两裤腿 | 胸前带节点、前中拼片、裙腰、花瓣下摆 |
| 连接 | 吊袜端点不接袍边，未知后部不补造 | 肩带、蝴蝶结及裤腿不重复 | 整体四吊袜关系正确，不把后部全移到前部 |
| 人物 | A的脸、体型、肤色与姿态保持 | 同左 | 同左 |
| 环境摄影 | 真实美国生活空间，动机光一致 | 同左 | 同左 |

检查衣服边缘、手指、腋下、腰口、袍层和吊袜端点时放大查看；鱼网应是开孔网络，而不是画在薄纱上的菱形装饰。不要用锐化、加颗粒或后期字幕掩盖产品错款。

- **通过：**SKU、颜色、材质、穿法、关键结构与人物均正确，未知面没有被虚构。保存 M、参考图顺序和实际提示词。
- **局部修复：**仅一两个位置有偏差，主体与布局已正确；选择对应修复词，做一次定向修复并重新验收。
- **停止：**缺必要参考、错款范围大、出现审核拒绝，或一次定向修复后仍有关键产品错误。记录原因，不标为可发布，不无限重试。

### 已有母图后如何进入视频

这一节是制作流程建议，不是独立视频提示词。

- 以通过验收的 M 做首帧，避免同时把“换装、换脸、换房间、转身、抱猫”都交给视频阶段。
- 在项目已批准的 Format A/B 中，复杂结构优先考虑 Format B 的 8–10 秒简单展示；这只是当前项目时长选择，不代表实测成功率保证。
- 先测试自然呼吸、轻微重心变化或小角度侧身；没有背面证据的 015 不安排背面揭示。
- 001 不靠拉裙或大幅转身证明鱼网袜；保持袜口与连接点稳定。
- 056 不安排短裤与内裤互换，也不让上衣下摆与短裤腰口反复遮挡。
- 原创发布视频仍按项目规则另写完整产品锁、人物/背景/光线、前1–3秒Hook、动作状态链、相机与紧凑负面词；不把静态母图提示词直接当完整视频脚本。
- 使用本项目视频中转脚本时，超时继续查询同一任务；不确定或失败结果不自动重提交。本文不执行上传、生成或付费操作。

## 11. 给提示词助手用的总指令

下面这段给负责写提示词的 Grok/其他文本助手使用，**不是给图片模型直接生成的提示词**。使用时一并提供对应商品事实和参考图片；没有本文件或产品资料时，助手不能凭款号知道衣服。

```text
你的任务是优化CHALOVELO 015、056或001的Grok成年模特服装上身合成提示词。每次只处理一个SKU、一个颜色、一位成年大码模特，输出中文图片编辑提示词。

先检查输入：当前SKU与颜色、TikTok商品事实、模特底图A、对应产品图B、要改的部位、已经观察到的失败现象。商品链接控制客观款式/材质/件数/颜色/尺码；图片只补充清楚可见的结构，不覆盖链接。链接不可读就注明使用快照及日期，未知保持未知，不借另一个SKU补齐。

A是唯一人物来源，B只绑定衣服，分别控制人物、产品和场景，不让产品图人物替换A。保留原脸、肤色、体型和既定姿态；需要换姿态或背景时拆成独立步骤。模特必须明确成年，使用项目批准的美国市场大码选角。每份完整上身提示词包含实见脸型、头发、自然皮肤、妆容、表情、视线、姿态、手脚状态，身高in、体重lb、商品可售尺码与内部造型数据性质，以及具体美国生活背景与可解释的光源方向、阴影和材料受光反应。

先明确本轮要改什么，再写SKU产品锁、穿着关系、保留项与短负面约束；不是越多形容词越好。015强调长袖长开襟蕾丝外袍与内搭/下装分离，商品名称重叠不生成第五件；056强调缎面不透明，上衣、短裤、bikini内裤分别管理，短裤外穿时内裤在里面，无真实短裤图不做完整短裤穿法；001强调胸前带节点、前中蕾丝、短褶裥裙、花瓣荷叶边、四吊袜整体关系与一双蕾丝袜口鱼网袜，隐藏后部不挪到前部，内裤不宣传为已确认随附件。三款都不得补造未知结构或改变原透明度。

区分首次完整换装与已有图局部修复。已有主体正确时仅输出一条准确的局部修复指令，不重复整套新场景。生成范围大错或缺关键参考时先报告缺口。审核拒绝、网络错误、限流和视觉错款分开记录，不写绕过审核或保证成功的措辞，不自动提交生成。

输出顺序：1. 本轮目标与必要缺口；2. 引用图片的顺序和用途；3. 一份完整可复制主提示词，或一条对应局部修复词；4. 三至五条与本款相关的验收要点。必要澄清只问一个关键问题，其余根据已确认输入继续。不要输出隐藏推理、虚构模型参数、价格、折扣、平台合规保证或未经实测的成功率。
```

## 12. 怎样验证它是否更有效

先在同事实际使用的 Grok 入口做小规模对比。每款固定同一 A、同色产品参考和相同可见设置，旧词与新词各做少量同条件尝试；测试次数由可接受的额度或费用决定。一次成功不能证明概率改变，样本少时只说“本轮观察”。本包没有执行这些测试。

| 记录字段 | 填写内容 |
| --- | --- |
| 入口与模型 | 网页/App/官方API/第三方；实际可见或返回的模型，不凭名字猜内部模型 |
| 任务类型 | 静态换装/局部图片修复/图生视频，分别统计 |
| 输入 | SKU、变体、A/B文件名、附件顺序、必要参考是否完整 |
| 提示词 | 原词/本包版本/局部修复词，保存实际提交全文 |
| 设置 | 当前入口实际支持的画幅、质量等设置；没有显示的不伪造 |
| 服务结果 | 出图、拒绝、仍在等待、技术失败、原因未知；保留原始提示或任务ID |
| 衣服验收 | 款式、材质、件与穿法、连接、颜色分别通过/不通过 |
| 人物验收 | 同脸、同体型、同肤色与姿态是否保持 |
| 成本与修复 | 实际耗时/费用/额度、是否做过一次局部修复 |

可分别记录：

- 出图率 = 返回图片的任务数 / 状态已明确的提交任务数。
- 商品通过率 = 商品验收通过的图片数 / 返回图片数。
- 一次完成率 = 不经修复就通过完整验收的任务数 / 状态已明确的提交任务数。
- 审核拒绝、技术失败与未知原因单列；仍等待中的任务不当作失败。

多候选输出要同时记任务数和候选图数，不能把一次任务产出的多张图当作多次独立提交。旧词与新词比较时使用同一口径，不把视频下载率和静态上身准确率放进同一列。
